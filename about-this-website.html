About This Website

An unofficial educational website created by Red Phylax Republic as a final project for Introduction to Computing.

RPR

Project Credit

Created by Red Phylax Republic

This website was designed and developed by Red Phylax Republic as our final project in Introduction to Computing. It demonstrates the use of semantic HTML and responsive CSS to organize and present information about Batangas State University.

The project is educational and non-commercial. It is not an official Batangas State University website and is not affiliated with, endorsed by, or maintained by the University.

Important Information

About the Project

  1. Educational Purpose

    The website was produced to apply introductory computing concepts, web page structure, responsive design, and accessible navigation in a complete class project.

  2. Institutional Materials

    The BatStateU name, BSU Seal, Red Spartans mark, CORE Values graphic, and other institutional materials belong to Batangas State University or their respective rights holders. They are included solely for educational, non-commercial presentation.

  3. Information Notice

    Content was compiled from supplied project references and publicly available university information. Details may change, so official policies, requirements, dates, and contact information should always be confirmed through BatStateU’s official channels.
