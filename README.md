# Batangas State University Information Website

An unofficial, non-commercial student project created by **Red Phylax Republic** for Introduction to Computing.

## Project structure

```text
.
├── index.html                  # Home page
├── about.html
├── about-this-website.html
├── academics.html
├── admissions.html
├── contact.html
├── faculty-staff.html
├── news.html
├── student-life.html
├── assets/
│   ├── css/
│   │   └── styles.css          # Shared styles for every page
│   └── images/                 # Website image assets
├── package.json
└── vite.config.ts              # Local preview and multi-page build setup
```

## Open without installing anything

Open `index.html` in a browser. Keep the HTML files and `assets` folder together so styles and images load correctly.

## Editing

- Edit shared appearance in `assets/css/styles.css`.
- Edit page content in the corresponding HTML file.
- Add image files under `assets/images/` and reference them with paths such as `assets/images/example.png`.

No client-side JavaScript or framework is used.

Enjoy!
